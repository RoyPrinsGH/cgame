# CGAME

Cgame is very WIP, but is planned to be a very simple game engine that allows you to create simple multiplayer games that are driven by Luau scripting 

## AI usage

AI was not directly used for code generation. All code here was written by hand by me.
AI was used for providing sources and guidance on learning the lirbaries involved in the project, and with providing dummy code for certain functionalities (e.g, "how do i use a quaternion to rotate an instance of a raylib model?")
