# CGAME

Cgame is very WIP, but is planned to be a very simple game engine that allows you to create simple multiplayer games that are driven by Luau scripting 

## Supported targets

Linux and windows (x64)

## Scripts

Scripts are meant to be run with [jao](https://github.com/RoyPrinsGH/jao)=

## AI usage

AI was not directly used for code generation, with the exception of the windows-specific part of mapped_file.cpp, where I asked ChatGPT to translate my linux code into windows for the cross-compile. All other code here was written by hand by me
Other than that, AI was used for providing sources and guidance on learning the lirbaries involved in the project, and with providing dummy code for certain functionalities (e.g, "how do I set up instancing for my ship model? provide a runnable standlone example")
